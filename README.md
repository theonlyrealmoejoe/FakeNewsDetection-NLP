# Fake News Detection and Thematic Categorization

This repository contains the complete research project: "Thematic Categorization of Fake News in Online News Outlets" by Mohammad Torabi.

## 📄 Contents
- `data/`: Datasets used in the study
- `figures/`: Visualizations (classification results, topic distributions)
- `models/`: Trained model files (to be added)
- `notebooks/`: Jupyter notebooks for preprocessing, training, and evaluation
- `src/`: Source code for feature extraction, training, and utilities
- `results/`: Model outputs and performance metrics
- `docs/`: Paper manuscript and supplementary materials

## 🧠 Methods
The study compares Naïve Bayes, SVM, and LSTM models for binary and multi-class fake news detection using the ISOT and HuffPost datasets, applying preprocessing, TF-IDF, and SMOTE where applicable.

## 📊 Key Results
- LSTM achieved 99.72% accuracy on ISOT and 84.6% on HuffPost
- Political news had the highest fake news prevalence
